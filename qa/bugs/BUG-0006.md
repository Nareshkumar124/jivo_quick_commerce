# BUG-0006: Staff session lasts a fixed 12 hours; the doc requires 8 hours, and 2 hours idle for admin roles

| Field | Value |
|---|---|
| Bug ID | BUG-0006 |
| Module | backend settings: `config/settings/base.py` (`SESSION_COOKIE_AGE`), staff session login (P1) |
| Owner agent | `django-backend-dev` (settings). The per-role policy may need `admin-panel-dev` input. |
| Severity | **P3 Minor** (brief scale: **Low**) |
| Priority | P3 |
| Status | **Fixed – partially verified** (2026-11-09, `4ac5dae`): cookie expiry per role verified; the `shortsession` idle/absolute timeline not re-run (see "Verification") |
| Found | 2026-11-02, QA run 1 (configuration review) |
| Environment | Commit `4960527`. Same values in local, staging and production settings. |

## Steps to reproduce
1. Load any settings module and read `SESSION_COOKIE_AGE`: 43200 (12 h). `SESSION_SAVE_EVERY_REQUEST` is not set (Django default `False`).
2. Sign in to `/admin/` as a seeded staff user. The session cookie expires 12 h after login, whatever the activity, and there is no idle expiry.

## Expected
05 §5 (Panel non-functional notes): "Session timeout 8 hours (store staff) / 2 hours idle (admin roles)". 09 §3.1: "session expiry".

## Actual
One fixed 12-hour absolute lifetime for every staff role. There is no 2-hour idle timeout for admin roles (Super Admin, Ops, Finance, Support, Catalog), and the absolute limit is 12 h, not 8 h.

## Evidence
```
production settings dump: ... SESSION_COOKIE_AGE 43200 ...
$ grep -rn "SESSION_SAVE_EVERY_REQUEST\|SESSION_EXPIRE_AT_BROWSER_CLOSE" backend/config  -> (no matches)
```

## Possible root cause
`config/settings/base.py:131`: `SESSION_COOKIE_AGE = env_int("DJANGO_SESSION_COOKIE_AGE", default=60 * 60 * 12)`. There is no per-role or idle handling.

## Suggested resolution
Set the absolute default to 8 h. Add idle expiry for admin roles: for example, middleware that sets `request.session.set_expiry(2 * 3600)` on each request for users in admin groups, or `SESSION_SAVE_EVERY_REQUEST` with a 2 h age for those roles. If the doc's numbers are meant only for the Phase 4 Ops Console, record that decision in 05 §5 instead.

## Verification (2026-11-09, QA P5–P7 run, `4ac5dae`)
Fixed in P2 R3 (`apps.accounts.middleware`, 05 §5). `tests/test_p1_staff_session.py::test_p1_tc95_cookie_expiry_per_role` on the QA instance (local profile): **passed**. The Super Admin session cookie expires at login + 2 h (idle rule for admin roles) and the Store Staff cookie at login + 8 h (absolute). The idle/absolute timeline under the `shortsession` profile (P1-TC-95 part 2) was not re-run in this pass; it remains in the regression set.
