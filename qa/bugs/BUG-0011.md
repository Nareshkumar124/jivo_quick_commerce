## Steps to reproduce
Log in as Super Admin, open `/admin/orders/order/`, look for an export (CSV) action or button.

## Expected
05 §2 "Orders" (P4): "Actions: … **export CSV**." Exports escape formulas (`apps.core.export_formats.escape_formula`, P4-TC-40).

## Actual
No export action or button on the order list (`get_actions()` returns `{}`; the page has no "export" text). The other filters work: status, store (scoped), payment method, payment status, date, customer; coupon code is searchable.

## Suggested resolution
Add the export the catalog admin already uses (django-import-export with `escape_formula`, store-scoped queryset, masked phone for roles without full PII). "Resend invoice" (also in 05 §2) needs DELIVERED orders and can follow in Phase 5.
