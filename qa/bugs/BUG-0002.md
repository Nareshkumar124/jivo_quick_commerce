## Public summary (data-integrity part)
Steps:
1. `POST /api/v1/addresses/` with `"pincode": "1२२००१"` (Devanagari digits after an ASCII first digit).

Expected: `400 VALIDATION_ERROR`. The published contract pattern `^[1-9]\d{5}$` is ASCII-only for the Dart and JS clients, and 07 §2.1 requires a 6-digit PIN code.

Actual: `201 Created`, and the non-ASCII PIN code is stored. The same class of input is accepted by other numeric fields covered by the tests above.

Suggested direction: make the numeric validators ASCII-only (`[0-9]`, or `re.ASCII`) everywhere, model validators included, and add regression tests.
