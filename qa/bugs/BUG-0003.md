## Public summary
- 06 §2.1 and the schema state that a refresh token "works exactly once". QA found a reproducible condition in which this does not hold.
- Sequential reuse is correctly rejected with `401 TOKEN_INVALID` (P1-TC-24 passes).
- Revoke-all on account deletion and on a Customers-admin block still reaches every affected token.
