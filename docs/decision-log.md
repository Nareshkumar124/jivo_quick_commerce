# Technical Decision Log

This is the index of the project's architectural and process decisions. It serves as the ADR index the docs refer to. Product decisions that wait on Jivo stay in [`11-open-decisions.md`](11-open-decisions.md).

Only the main session (Project Manager) edits this file. A new decision gets a row here plus updates to the docs it affects.

**Decided by:**
- **User:** you decided it explicitly.
- **PM default:** chosen by the main session to keep work moving. ⚠ means it is waiting for your confirmation. Overrides are welcome.
- **Agent:** an agent chose it and the PM accepted it.
